How this board is built — read this first

Implied value = TVL × curve anchor × growth × maturity × breadth. The anchor is not a flat number: it comes from a log-log comps curve fitted to the snapshot's own tokenised peers, A flat median multiple would price a $10M protocol and a $10B protocol the same way; the peers say the multiple falls steeply with size, so the curve does the pricing.

Tested blind. The model was frozen first, then scored on five 70/30 hold-out splits of the tokenised peers (fixed seeds, the curve re-fitted on the 70% only, scored only on the 30% it never saw): The median margin is small, so this is evidence the curve does not overfit, not proof it is dramatically better — the table below shows all five seeds, not a cherry-picked one.

Costed farm plans. Every row's plan names what each step costs in network fees and how long it takes, from a stated gas table per chain and a stated capital tier by TVL. The totals are the sums of the steps. Gas figures are the model's own estimates, not live quotes — the snapshot carries no fee data.
